# Smile Dental Studio

Fictional static dental clinic portfolio demo. The website uses no backend, database, or secrets.

Edit the CLIENT CONFIGURATION block at the top of app.js to change clinic name, phone, WhatsApp number, address, opening hours, services, team placeholders, and colors. Update matching CSS variables in index.html if changing the palette.

Keep noindex enabled until a real client approves the live website. The form opens a prefilled WhatsApp message and does not store form submissions. Replace all placeholder contact details before use.

Demo website for portfolio purposes. Not a real clinic.
